# AppSec Open Source Intelligence

## Overview

The purpose of this page is to gather resources that can be used to stay on the latest AppSec trends and watch for new and immerging attack vectors and dangerous packages.

*NOTE: None of these sources is fully vetted for signal-to-noise ratio.  This is what I am starting with and will purne and add over time.*
